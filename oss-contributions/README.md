# OSS Contributions

머지된 PR·작성한 이슈를 시간순으로 기록. **머지 이력 자체가 시그널**.

## Format

```markdown
## YYYY-MM · <repo> · <PR-or-issue>
- **Title:** ...
- **Type:** (bugfix|feature|docs|typo|test)
- **PR:** <URL>
- **Why:** 1줄 요약
```

## Targets (2025–2026 후보)

- `spring-projects/spring-framework`
- `JetBrains/kotlin`
- `langchain-ai/langchain`
- `openai/openai-python`
- `vercel/next.js`
- `goodfirstissue.dev` 큐레이션
