# Blog

깊이 있는 기술 글 **3~5개** = 17/26사 가산 시그널.

## 권장 주제

1. **기술 선택 비교** ("왜 Spring이 아니라 NestJS" 또는 "왜 GPT-4o-mini") — P2·P3에서 1개
2. **트러블슈팅 포스트모템** (재현→원인→해결→재발방지) — P2 동시성 이슈 등
3. **LLM 비용 최적화** (캐싱·배치·모델 라우팅) — P1 운영 후기
4. **RAG eval 결과 분석** (어떤 조합이 가장 faithfulness 높은가) — P3
5. **OSS 첫 기여 회고** (어떤 PR을 보냈고 왜 받아들였나) — P4

## 발행 채널

- 외부: Velog·Tistory·개인 사이트 (Medium·GitHub Pages)
- 내부: 본 레포의 `blog/` 에도 마크다운 보존
- 동기화는 `blog/<slug>.md`를 SSOT로

## 스타일 가이드

- STAR / Why-What-How-Tradeoff-Result 구조
- 코드 예시·스크린샷·표 포함
- 1,500~3,000자 분량
