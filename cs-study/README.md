# CS Study

26개사 공통 1차 컷 = **CS 기초 (자료구조·알고리즘·DB·OS·네트워크)**.

## 폴더 구조

- `algorithm/` — 백준/프로그래머스 풀이 + 원론적 사고 노트
- `db/` — 인덱스·트랜잭션·정규화·쿼리 최적화
- `os/` — 프로세스·스레드·메모리·동시성
- `network/` — HTTP·TCP·TLS·gRPC·REST vs GraphQL

## 원칙

- **"왜 이 알고리즘/구조를 골랐는가" 주석 필수** (토스 모닥불 기준)
- 단순 정답 코드가 아니라 **사고 과정**을 보이는 노트
- GitHub Actions로 자동 검증 (TDD)
